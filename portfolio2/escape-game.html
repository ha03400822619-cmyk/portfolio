Room Escape Game

A multi-level Windows desktop game built entirely with C#, .NET, and Windows Forms.

🎮 Game Features & Architecture

  • Core Tech: Developed in C# using Windows Forms (.NET) and System.Drawing for graphics.
  • OOP Architecture: Extensively uses Encapsulation, Inheritance, Polymorphism (e.g., Enemy AI behavior), and Composition.
  • Database Integration: Uses SQL Server LocalDB for persistent data storage, including User Authentication (Login/Registration) and Global Leaderboards.
  • Gameplay Mechanics: Features Player animations, Enemy AI with collision detection, interactive puzzles/riddles, power-ups, and a life/health system.
  • Game Flow: Includes multiple difficulty levels, settings management, and pause/resume functionality.
